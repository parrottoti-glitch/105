# اتوکلیکر اندروید

کلیک خودکار با دقت میلی‌ثانیه، زمان‌بندی شروع، نوار شناور پلی/استاپ و تم تاریک.

## امکانات
- فاصله‌ی بین کلیک‌ها به میلی‌ثانیه
- تعداد ضربه (دستی با دکمه‌های + و −، صفر = بی‌نهایت)
- شروع زمان‌بندی‌شده (ساعت:دقیقه:ثانیه.میلی‌ثانیه)، مثلاً ۰۸:۳۰:۰۰.۰۵۰
- پیش‌دستی (جبران تأخیر) به میلی‌ثانیه
- نوار شناور (▶ / ■ / ✕) و دایره‌ی هدف قابل جابه‌جایی

## بیلد
**روش ۱ (بدون Android Studio):** پروژه را در گیت‌هاب آپلود کن، به تب Actions برو، workflow به نام Build APK را اجرا کن و فایل `AutoClicker-debug` را از Artifacts دانلود کن.

**روش ۲:** پروژه را در Android Studio باز کن و Build > Build APK را بزن.

## استفاده
1. APK را نصب کن و برنامه را باز کن.
2. «فعال‌سازی سرویس دسترسی» را بزن و اتوکلیکر را روشن کن.
3. تنظیمات را وارد کن و «نمایش نوار شناور و هدف» را بزن.
4. دایره‌ی قرمز را روی نقطه‌ی مورد نظر ببر و ▶ را بزن.

## نکته‌ها
- فاصله‌های زیر حدود ۱۰ میلی‌ثانیه ممکن است روی بعضی گوشی‌ها دقیق اجرا نشوند (محدودیت خود اندروید).
- ساعت گوشی را روی «خودکار (شبکه)» بگذار تا زمان‌بندی دقیق باشد.
- اگر زمان تنظیم‌شده گذشته باشد، برای فردا زمان‌بندی می‌شود.
